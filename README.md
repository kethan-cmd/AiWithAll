# AI with All Hackathon: Money on the Table

Family caregivers of people with dementia leave benefits unclaimed because the paperwork is the bottleneck. **Money on the Table** reads the documents a family already has, finds likely programs, pre-fills the applications, and turns what's left (sign, submit, find a provider) into tasks the family shares.
