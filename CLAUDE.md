# AI with All Hackathon

This repo supports a one-day no-code hackathon (AI with All) where our team builds a Base44 app.

## Rules

- The comp-day guides in this folder are the source of truth for setup steps.
- Always create a Base44 checkpoint before making changes to the app.
- Make small, targeted edits. Never refactor, rename, or restructure Base44's generated files.
- My teammates are beginners: explain every change in plain language.
- If the same approach fails twice, stop and summarize instead of trying more variations.
